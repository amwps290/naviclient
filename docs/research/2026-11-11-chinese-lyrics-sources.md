# 酷狗与网易云歌词来源评估

日期：2026-11-11。目标：补充中文歌曲覆盖，保留现有 LRCLIB 和原音乐源歌词策略。

## 接口与样本

本次直接访问以下 HTTPS 接口，无账号、Cookie 或用户 API Key。只请求歌曲元数据与歌词，不请求音频，也不把音乐源凭据交给歌词平台。

| 来源 | 搜索 | 取得歌词 | 已核对的样本 |
| --- | --- | --- | --- |
| 酷狗 | `lyrics.kugou.com/search`，`keyword`、可选毫秒 `duration` | `/download`，候选 `id` 与临时 `accesskey`，`fmt=lrc&charset=utf8` | 稻香 / 周杰伦，候选时长 222563 / 223503 毫秒；Base64 解码为 UTF-8 LRC |
| 网易云音乐 | `music.163.com/api/search/get/web`，`s`、`type=1`、`limit=10` | `/api/song/lyric`，`id`、`lv=-1&kv=-1&tv=-1&rv=-1`；按 ID 恢复时先请求 `/api/song/detail` | 十年 / 陈奕迅，搜索 ID 66842 / 65326，205423 / 205000 毫秒；海阔天空 / Beyond，ID 347230，326000 毫秒，下载 LRC 已核对 |

搜索元数据与歌词需要分开获取。酷狗候选包含字符串 ID、歌名、歌手、毫秒时长和临时下载键；网易云候选包含 ID、歌名、歌手数组、专辑及毫秒时长。网易云按 ID 恢复时核对详情中的 ID，避免把错误歌曲的信息用于显示。

两者的 HTTP 成功还需核对 JSON 中的 `status` / `code`。缺少歌词不推断为纯音乐；HTTP 错误、限流、无效 JSON、错误 Base64 或 UTF-8 不表示“无匹配”。临时下载键只在一次酷狗检索与下载中使用，缓存中保存来源、稳定 ID、元数据与正文；恢复选择时重新检索下载键。

已用实际 Rust 客户端分别完成酷狗《稻香》/ 周杰伦 / 223 秒、网易云《十年》/ 陈奕迅 / 205 秒的搜索、严格元数据匹配和按候选 ID 再次获取同步歌词。两个测试显式运行通过，结果不依赖手工拼接 curl 请求。

这些是当前可匿名访问的网页客户端接口，不是带稳定性承诺的官方开发者 API。样本验证不能推断整个曲库覆盖率，也未逐首播放音频核对歌词或时间轴。接口变化、地区限制或限流可导致暂时不可用，因此保留来源开关、手动选择和其他来源回退。

## 实施决策

- 三个来源独立开关；旧配置默认仅选择 LRCLIB，用户明确启用酷狗或网易云后才访问新来源。
- 自动查询固定按 LRCLIB → 酷狗 → 网易云执行，禁用的来源跳过。严格检查歌名、歌手、版本和 ±2 秒时长；多个可信但不同的时间轴仍交给用户选择。
- 手动搜索并发检索已启用来源，可筛选单一来源；候选与当前歌词显示实际来源。一家失败不会丢弃其他家的可用结果。
- 酷狗最多检查 20 条元数据，网易云最多检查 10 条；先排序，再分别下载前 5 条歌词。每家请求串行，间隔至少 300 毫秒，独立冷却，每轮预算 8 秒。候选下载中途失败则本家查询失败，不能据不完整结果负缓存或自动认定唯一匹配。
- 自动查询、负缓存、正文和单曲固定选择带歌词来源身份；不同平台使用相同数字 ID 时不会冲突。LRCLIB 旧缓存键与选择仍可读取。
- 继续支持原音乐源优先、在线优先、仅手动搜索，以及独立网络连接设置；关闭联网后仍能使用已保存的固定歌词和偏移。

合约与回归测试位于 `src/lyrics/{kugou,netease,service,cache}/tests.rs`。真实接口测试默认忽略，可显式运行 `cargo test live_ -- --ignored`；它们只验证上述两个来源的搜索、匹配与按 ID 下载，不依赖线上服务运行日常测试。

最终检查：1365 项日常测试通过，5 项忽略（3 项已有凭据集成测试、2 项上述真实接口测试）；两个真实接口测试另行运行通过。Clippy `-D warnings`、格式检查和开发构建通过。使用临时配置检查了英文设置来源开关及其保存结果、原音乐源优先显示、宽窄窗口搜索入口和来源筛选布局；未逐首音频核对，也未完成 Windows 与所有界面语言的人工全流程验收。
