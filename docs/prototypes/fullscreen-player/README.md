# NAVI 全屏播放器交互原型

四套独立视觉方向，共用左侧封面、右侧歌词和底部播放控制。纯 HTML、CSS、JavaScript，无需安装依赖。

已选定 **04 黑胶沙龙** 作为全屏播放器的设计方向，预览默认进入这一方案。采用香槟金和炭黑配色，左侧旋转唱片与唱臂、右侧大歌词、底部播放控制；其余方案保留用于对比。

| 方案 | 方向 | 建议场景 |
| --- | --- | --- |
| 01 暮色剧场 | 封面色背景、大歌词、柔和波形 | 电视、投影、大屏聆听 |
| 02 白昼画廊 | 暖白、装裱封面、衬线歌词、轻频谱 | 明亮环境，延续应用现有暖白风格 |
| 03 夜航现场 | 炭黑、青绿色高亮、可见节拍频谱 | 动态演示、活动背景 |
| 04 黑胶沙龙 | 香槟金、旋转唱片、唱臂、衬线歌词 | 已选定；延续现有黑胶特色，安静聆听 |

在仓库根目录启动：

```sh
python3 -m http.server 8766 --bind 0.0.0.0 --directory docs/prototypes/fullscreen-player
```

打开 `http://服务器地址:8766/`。SSH 端口转发可使用：

```sh
ssh -N -L 8766:127.0.0.1:8766 用户@服务器
```

然后在本机浏览器打开 `http://127.0.0.1:8766/`。可通过 `?design=cinema`、`?design=gallery`、`?design=stage`、`?design=vinyl` 直接进入某一方案。

支持切换方案、播放暂停、三首示例曲目切换、进度拖动、点击歌词跳转、逐字进度、译文开关、收藏、随机、单曲循环、波形/频谱切换、静音/音量、浏览器全屏、纯净展示。全屏后鼠标静止时控件淡出，移动鼠标唤回。

快捷键：`1`–`4` 切换方案，`Space` 播放暂停，`F` 全屏，`H` 隐藏/显示控件，`T` 切换译文，`V` 切换视效，`←`/`→` 前后跳转 5 秒。

预览默认静音并演示动态效果；点击喇叭才会生成并播放原创氛围音轨。声音开启时频谱使用 Web Audio 分析器，静音时使用示意动画。所有封面、歌曲和歌词均为原创示例，未接入客户端的实际播放状态。曲目没有合成人声。纯静态资源，没有 CDN、后端数据请求或用户凭据。

以桌面和 16:9 演示屏幕为主，同时适配窄屏。遵循 `prefers-reduced-motion`。用于固定画面检查时，可在网址添加 `&freeze=1&t=84`；此参数只冻结示例歌曲进度。
