# 界面视觉与版式重构设计

日期：2026-11-06
状态：待审阅

## 背景

现在的界面像“工业软件”，不像一个听歌的娱乐软件。原因主要有四个：

- 窗口被细线切成侧栏、内容、播放条三块，歌曲行、区块标题、设置分组也都靠横线分隔。
- 配色基本是组件库默认的中性灰。
- 首页一打开先是服务器连接状态，下面是几组等权的专辑网格。
- 播放条上有格式、码率这类技术标签。

2026-10-29 的设计评审（`.impeccable/critique/`）也指出：只有“正在播放”页有自己的辨识度，浏览页像曲库管理工具。

代码层面，视觉数值散落在各个页面里：`src/app` 下有 327 处写死的像素值、55 处写死的颜色。只换组件库主题色，只能改掉一小部分观感。

## 目标

让应用看起来像一个现代的听歌软件：明亮、温暖、有杂志感，同时保留黑胶唱机这个最有辨识度的部分。改完以后，视觉数值集中在一处定义，以后调整只改一处；首页能以“加一个货架”的方式接纳新功能。

## 已确定的方向

| 主题 | 决定 |
|---|---|
| 风格 | C“明亮杂志”：暖白底、大留白、衬线大标题、悬浮卡片 |
| 深色模式 | 浅色为主。深色由同一套规则推导为暖黑，版式完全一致；只保证协调和对比度达标，不单独做视觉打磨 |
| 强调色 | 界面框架用固定品牌色；封面色只用在内容上 |
| 品牌色 | 玫瑰红 |
| 范围 | 视觉加版式，所有功能和交互规则不变 |
| 正在播放 | 保留黑胶唱机和唱臂，融入新风格 |
| 首页 | 模块化货架 |
| 网格 | 统一列网格，宽屏多放、窄屏少放，不设内容最大宽度 |

## 范围

**包含：**

- 新的设计规则模块，以及组件库浅色、深色主题的全局颜色覆盖
- 衬线标题字体的平台选择与回退
- 窗口框架：标题栏、侧栏、悬浮播放条、悬浮队列抽屉
- 首页货架化
- 媒体库网格页、详情页、歌曲列表、搜索页
- 正在播放页、设置、弹窗、迷你播放器
- 几条新文案（问候语、侧栏分组名），三种界面语言都要补
- 更新 `README.md` 和 `DEVELOPMENT_PLAN.md` 中受影响的界面描述

**不包含：**

- 任何交互规则的变化：歌曲行单击选择、双击播放，以及右键菜单、多选、快捷键、折叠、拖动都保持原样。评审里提到的其余交互调整（如次要按钮只在悬停时出现），以后另做。
- 新功能。首页货架设计四种样式，但这次只实现现有内容用到的两种。
- 打包字体文件。
- 播放、音频、数据、配置格式的任何改动。

## 工作方式约束

- 直接在工作区修改，不创建分支，不提交。本 spec 和后续计划也只写入、不提交，由用户自己提交。
- 每完成一个阶段，程序必须能正常运行，标准验证全部通过。
- 这台机器上 KWin 拒绝了截图请求，所以视觉效果由用户截图或查看后反馈。如果实施时找到可用的截图方式，改为自行检查。

## 设计规则

### 颜色

| 名称 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 页面底 | `#F7F3EE` | `#1C1917` | 窗口、标题栏、侧栏、内容区的统一底色 |
| 浮起表面 | `#FFFFFF` | `#292524` | 卡片、播放条、队列抽屉、弹层、菜单 |
| 凹陷表面 | `#EFE9E2` | `#24201E` | 悬停底色、输入框、次要按钮 |
| 正文 | `#1C1917` | `#F5F5F4` | 标题、歌名 |
| 次要文字 | `#57534E` | `#D6D3D1` | 艺术家、元信息 |
| 弱化文字 | `#6F6863` | `#A8A29E` | 计数、列头、说明 |
| 品牌 | `#B53660` | `#F28AA8` | 选中、链接、主按钮、进度、正在播放 |
| 品牌淡底 | `#F2E4E3` | `#3A292B` | 导航选中、正在播放行、开关打开状态 |
| 品牌上的文字 | `#FFFFFF` | `#1C1917` | 主按钮上的图标和文字 |

所有文字和底色的组合都达到 WCAG AA 的 4.5:1。最紧的一组是浅色下品牌色写在品牌淡底上，为 4.64:1；正是为了这一组，品牌色从草图里的 `#BE3A63` 调成了 `#B53660`。

规则：

1. 品牌色只表达状态和动作，其余文字一律用中性色。
2. 封面色只铺在内容表面上：首页继续聆听卡、详情页头部、正在播放页背景、迷你播放器背景。按钮、开关、进度条、选中态都不跟随封面变色。
3. 删除、错误类操作继续使用组件库主题里的红色语义色。
4. 封面色铺底前先归一化：只保留色相，饱和度上限 0.6，亮度固定（浅色 0.62、深色 0.42），再按各表面的强度混入页面底色。这样无论封面多暗、多艳或是灰色，上面的正文和次要文字都不低于 4.5:1，由测试遍历色相验证。拿不到封面色时不铺色：详情页和正在播放页用页面底色，首页卡片用凹陷表面。

### 字体

| 层级 | 字号 | 字体 | 用途 |
|---|---|---|---|
| 详情标题 | 40 | 衬线粗体 | 专辑、艺术家、播放列表详情页 |
| 页面标题 | 32 | 衬线粗体 | 首页问候、媒体库网格页 |
| 卡片标题 | 26 | 衬线粗体 | 首页大卡片 |
| 区块标题 | 18 | 衬线粗体 | 货架、详情页分区、设置分组 |
| 正文 | 14 | 现有无衬线 | 歌名、按钮 |
| 次要 | 13 | 现有无衬线 | 元信息 |
| 说明 | 12 | 现有无衬线 | 计数、列头 |

正在播放页的歌名和歌词另有尺寸，见后文。

衬线字体按平台和语言选择，不打包字体文件：

- Linux：`Noto Serif CJK SC`、`Source Han Serif SC`（繁体界面优先 `TC` 版本）
- macOS：`Songti SC`、`STSong`（繁体界面优先 `Songti TC`）
- Windows 和找不到衬线字体时：回退为现有无衬线字体加粗

选择逻辑放在 `src/typography.rs`，与现有无衬线字体选择共用已安装字体列表和语言判断。

### 间距、圆角、层次

- 间距只用 4、8、12、16、24、32、48。页面边距 32，窄窗口 20；货架和分区之间 40。
- 圆角：8 用于按钮和行，12 用于封面和小卡片，20 用于大卡片、播放条和弹层，胶囊形用于胶囊按钮和搜索框。
- 不用分割线划分区域。侧栏、内容、播放条之间，以及歌曲行之间，都靠留白和表面色区分。边框只留给输入框，以及深色模式下的浮起表面。
- 阴影只用在浮起的东西上。浅色：`0 1px 2px` 加 `0 8px 24px`，颜色为正文色 6% 和 10%。深色下阴影不明显，浮起表面改用更亮的底色加 1px `#3A3431` 边框，再叠一层较深的阴影。
- 封面阴影：静止时 `0 6px 16px`，正文色 14%；悬停时加深。GPUI 没有位移变换，“悬停抬起”只通过加深阴影表现。

### 统一列网格

所有封面网格和货架都用同一套计算：

```
列数 = max(2, floor((可用宽度 + 20) / (160 + 20)))
列宽 = (可用宽度 - (列数 - 1) × 20) / 列数
```

可用宽度在当前帧直接算出：窗口宽度减去窗口阴影边距、侧栏宽度、队列抽屉（打开时）和页面左右边距。不读上一帧的布局结果，这样缩放窗口、开关抽屉时不会错位一帧，缩放结束后也不会停留在旧宽度上。

不设内容最大宽度。窗口越宽，一行放的封面越多，所有货架的左右边缘始终对齐。参考值：内容 800 宽为 4 列每列 185，1016 宽为 5 列每列 187。

## 组件

新增 `src/app/style.rs` 和 `src/app/style/`，作为第 19 个功能目录，负责：

- `tokens`：上面的颜色、字号、间距、圆角常量，以及按当前深浅模式取值的函数
- `theme`：组件库浅色、深色主题的全局颜色覆盖。替换 `app.rs` 里现有的 `adjust_light_theme_contrast`，保留它的圆角设置
- `surface`：浮起表面、凹陷表面、封面阴影的样式函数
- `grid`：统一列网格的计算（纯函数）
- `cover_tint`：由封面调色板生成内容表面渐变的函数，替代现在分散的 `home_feature_colors` 和正在播放背景计算

页面代码不再写 `hsla(...)` 和随手的像素值，统一从这里取。黑胶唱机的金属和唱片质感颜色属于插画，不属于界面规则，留在 `covers/view.rs` 原处。

货架组件放在 `src/app/widgets/`：

| 样式 | 这次实现 | 用途 |
|---|---|---|
| 大卡片货架 | 是 | 首页继续聆听、每日精选；以后的电台 |
| 方形封面货架 | 是 | 专辑和播放列表，单行，列数按统一网格 |
| 歌曲紧凑行货架 | 否，只定规格 | 以后的“最近听过的歌”：两列、行高 48、带小封面 |
| 标签行货架 | 否，只定规格 | 以后的流派、心情入口：一行可横向滚动的胶囊 |

货架统一由区块标题（衬线 18，可选折叠箭头）和内容组成，彼此相距 40。

## 页面设计

### 窗口框架

- 标题栏、侧栏、内容区都用页面底色，去掉侧栏右边线、播放条上边线和播放条内部的竖分隔线。
- 标题栏只保留详情页的返回按钮，以及右侧的迷你播放器、设置和窗口按钮。页面名称改由内容区的衬线标题承担。
- 侧栏宽 200。“主页”和“收藏”在上方，其余入口放进“媒体库”分组：分组标签从大写的 `LIBRARY` 改为普通大小写，中文仍是“媒体库”。选中项为品牌淡底加品牌色文字，计数用弱化文字。
- 服务器状态从顶部的填色胶囊，改为侧栏底部一行：状态圆点（已连接为绿色，连接中和离线为弱化色）、服务器名、折叠按钮。点击服务器名仍打开服务器设置，提示文字不变。
- 播放条变成悬浮卡片：距窗口边缘 12（窄窗口 8），浮起表面，圆角 20，高 72（窄窗口 64）。它仍占据自己的布局位置、不覆盖内容。播放按钮为 40（窄窗口 36）的品牌色圆钮；随机、循环、EQ、队列开关打开时为品牌淡底加品牌色。按钮的顺序、功能、提示都不变，技术信息标签的宽度阈值也不变。
- 队列抽屉变成与播放条相同的悬浮卡片，距右边缘和播放条 12，标题用衬线。仍与内容区并排，不遮挡内容；在正在播放页仍为覆盖层。
- 窄窗口（小于 1040）规则不变：侧栏只显示图标，宽 56。

### 首页

自上而下：

1. **问候**：衬线 32，按本地时间显示“早上好”（5 到 12 点）、“下午好”（12 到 18 点）、“晚上好”（其余时间）。去掉“主页”标题和服务器状态行。
2. **大卡片货架**：两张等宽、同高 176 的卡片并排，窄窗口高 144。
   - 左卡沿用现有逻辑：有正在播放就显示继续聆听，否则显示最近专辑。背景为封面色渐变，封面 128 加封面阴影，标题衬线 26，按钮和现在一样。
   - 右卡是每日精选：浮起表面，左边用今日歌单前 4 首的封面拼成 2×2；歌单未生成或不足 4 首时，空格显示默认封面。已生成时小标签是“每日精选”，衬线标题是“今日已精选 N 首”；未生成时衬线标题就是“每日精选”。标题下一行是说明文字，加载和出错提示也显示在这一行。按钮和现在一样：生成并播放或播放、加入队列、换一批。
3. **最近播放**：方形封面货架，不折叠。
4. **常听专辑、最新专辑**：方形封面货架，可折叠。
5. **随机专辑**：方形封面货架，默认折叠。

专辑货架只排一行，数量等于统一网格的列数，上限为该分组已取回的 30 张。继续聆听卡使用最近专辑第一张时，“最近播放”从第二张开始，和现在一样。

### 专辑卡片

- 封面圆角 12，加封面阴影。标题是正文 14 的普通文字，不再用按钮样式；下面一行是艺术家链接和年份。
- 悬停时封面阴影加深，右下角浮出 40 的品牌色播放钮，不再整块压暗。收藏按钮仍在右上角。
- 单击封面或标题进入专辑页，播放钮播放专辑，与现在一致。
- 艺术家卡片相同，只是图片为圆形，悬停播放钮位置不变。

### 媒体库网格页

艺术家、专辑、流派、收藏、播放列表这几页：

- 页头为衬线 32 的标题，下面一行数量；排序菜单、刷新、新建、导入等按钮放在右侧，功能不变。
- 网格使用统一列网格。
- 播放列表页从行列表改为封面网格，副标题显示曲目数和时长；别人共享给你的列表再加“共享”和所有者。点击进入详情不变，重命名和删除仍在详情页。
- 流派卡片改为色块：底色由流派名的稳定哈希在一组预设的柔和色中选取，同名永远同色；上面写流派名和数量。

### 详情页

专辑、艺术家、播放列表详情页共用一种头部：

- 背景：封面主色的淡色，从上往下渐隐到页面底色。浅色下主色强度 22%，深色下 18%。
- 左侧是封面，专辑和播放列表 220，艺术家 150 圆形，都加封面阴影。
- 右侧自上而下：类型小标签（“专辑”“艺术家”“播放列表”）、衬线 40 标题、元信息行（艺术家为品牌色链接）、按钮行。
- 按钮行：第一个按钮为 48 的品牌色圆钮，对应现在的主播放动作；其余按钮改为胶囊样式，种类和顺序与现在一一对应。
- 窗口较小（宽度小于 1040 或高度小于 760）时，封面缩到 140（艺术家 110），标题缩到 28，给歌曲列表留出高度。
- 头部贴满内容区边缘，所以这三种详情页的页面边距放在头部以下的内容上。

头部以下的分区（热门歌曲、专辑等）用衬线 18 的区块标题。

### 歌曲列表

- 行高 56，队列抽屉内 56。`SONG_ROW_HEIGHT` 相应从 61 改为 56，因为去掉了 1px 的顶部边框。
- 行间没有横线，行圆角 10。悬停为凹陷表面；键盘光标为品牌淡底；正在播放为品牌淡底加跳动音柱，音柱改用品牌色；多选沿用勾选方块，改为品牌色。
- 列头为 12 号弱化文字，去掉下边线。
- 专辑详情页里不显示每行的封面；收藏、搜索、播放列表、队列、历史等混合列表照旧显示 40 的小封面。
- 多选操作条为浮起表面加圆角 20。
- 单击、双击、右键、多选、快捷键、拖动行为全部不变。

### 搜索页

搜索框为高 44 的胶囊形凹陷表面，结果仍按艺术家、专辑、歌曲三组显示，分别套用上面的卡片和列表样式。

### 正在播放页

- 保留黑胶唱机、唱臂和旋转逻辑。
- 背景为页面底色上的封面色两色渐变：浅色下主色和强调色强度为 26% 和 20%，深色下为 20% 和 16%。现在的渐变角度随播放进度缓慢转动，改为静止。
- 标题栏与该页背景融为一体，不单独着色。
- 歌名衬线 30，艺术家和专辑为次要文字，艺术家为品牌色链接。“开始歌曲电台”改为胶囊样式。
- 歌词：当前行衬线 28、品牌色，保留淡入动画。其余行为衬线 20 正文色，不透明度随距离递减，最低 55%；现在最低是 28%，太淡、难以辨认。55% 在浅色页面底上约为 3.8:1，达到大号文字的 AA 标准。未同步歌词统一 72%。

### 设置

- 覆盖层为浮起表面，圆角 20，只用阴影，去掉边框。尺寸和左侧分区导航的结构不变。
- 每组设置不再各自套一个带边框的面板，改为衬线 18 的分组标题加 24 的组间距；组内行之间不画线。
- 所有选项、文案和行为不变。

### 弹窗

播放列表编辑、导入、删除服务器、歌曲信息这些弹窗，通过组件库主题统一为浮起表面、圆角 20、阴影。确认类主按钮使用品牌色，删除类继续用红色。

### 迷你播放器

- 背景改为页面底色上静止的封面色淡渐变，去掉现在 20 秒循环的装饰渐变动画。
- 控件按新规则换色：播放钮为品牌色，开关打开为品牌淡底。尺寸、窗口大小和功能不变。

### 提示、菜单、输入框、加载骨架

随组件库主题的全局颜色变化：菜单和提示为浮起表面，输入框为凹陷表面，骨架屏为凹陷表面色。

## 风险

| 风险 | 处理 |
|---|---|
| GPUI 没有背景模糊和位移变换，渐变只有两色 | 设计里已不依赖这些：浮层用不透明表面，悬停只加深阴影，所有渐变都是两色 |
| 组件库自带控件有些颜色不受主题覆盖 | 阶段 1 后逐个检查按钮、滑块、开关、菜单、弹窗，不符合时在调用处用自定义样式 |
| Windows 没有中文衬线 | 回退为粗体无衬线；三个平台标题字形不同，这是已接受的取舍 |
| 深色模式不单独打磨，个别组合可能不好看 | 对比度由测试保证；观感问题在用户检查时记录，留给后续调整 |
| 我这边无法截图 | 每个阶段由用户检查；若找到可用的截图方式则自行检查 |
| `cfg(windows)` 代码本机不能完整编译 | 用本机已验证的 Windows 类型检查方式检查，最终由 CI 的 `windows-latest` 验证 |
